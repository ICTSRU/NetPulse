# نبض الشبكة — SRU NetPulse · Brand pack v1.2

Approved concept: **option 6** — a ring (the network) enclosing a pulse line (connection quality), with the Arabic name «نبض الشبكة» as the primary wordmark and *SRU NetPulse* beneath it.
All lockup text is converted to outlines, so the SVGs display identically without the Cairo font installed.

## Colours
| Use | Hex |
|---|---|
| Ring / Arabic wordmark | `#501e8c` (SRU purple) |
| Pulse | `#1ba3d6` (cyan) — on dark backgrounds `#5cc8f0` |
| Latin wordmark | `#0a6eaa` (SRU blue) |
| Dark background | `#3a1464` |

## Usage rules
- Clear space around the logo ≥ the pulse line height; minimum lockup width 120 px, minimum symbol 24 px (use `favicon.svg` below that).
- Do not recolour the ring and pulse with other colours, stretch, rotate, or add effects/shadows.
- In co-branding, the SRU logo leads (right) and ICTD sits left; the NetPulse lockup sits between or below them.
